📂 /tCash/uploads/README-u.txt
Purpose: This folder contains all uploaded attachments (EXP_...) and Payout Reports.
Installation: This folder MUST have write permissions (CHMOD 775).

DK: Formål: Denne mappe indeholder alle uploadede bilag (EXP_...) og Payout Reports.
    Installation: Denne mappe SKAL have skriverettigheder (CHMOD 775).


📂 /tCash/backups/README-b.txt
Purpose: This folder stores the system's automatic ZIP backups and SQL dumps.
Important: Regularly download these files for local storage and delete them from the server afterwards.

DK: Formål: Her gemmes systemets automatiske ZIP-backups og SQL-dumps.
    Vigtigt: Download jævnligt disse filer til lokal opbevaring og slet dem fra serveren bagefter.


📂 /tCash/json-data/README-j.txt
Purpose: Contains configuration files such as languages.json.
Warning: Do not delete files in this folder, as the system will lose its language settings.

DK: Formål: Indeholder konfigurationsfiler som languages.json.
    Advarsel: Slet ikke filer i denne mappe, da systemet så mister sine sprogindstillinger.


📂 /tCash/temp_restore/README-t.txt
Purpose: Temporary workspace for extracting backups during restoration.
Note: The system normally cleans up this folder automatically, but the directory must exist for the process to initiate.

DK: Formål: Midlertidig arbejdsmappe til udpakning af backups ved gendannelse.
    Note: Systemet rydder normalt selv op her, men mappen skal eksistere for at processen kan starte.
